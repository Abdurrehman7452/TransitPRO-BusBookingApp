# TransitPRO – Bus Ticket Booking System

**TransitPRO** is a desktop-based C# Windows Forms application that allows users to book intercity bus tickets across various cities in Pakistan. Designed with a clean interface and logical flow, the app lets users sign up, log in, view available routes, and reserve seats by gender-validated selection.

---

## 🚀 Features

- 🔐 User Authentication (Login & Signup)
- 🚌 Search buses by departure & arrival city
- 📅 View schedule, trip duration, and ticket prices
- 💺 Interactive seat selection with gender validation
- 📞 Contact Us & FAQs section

---

## 🛠 Tech Stack

- **Language:** C#
- **Framework:** .NET (Windows Forms)
- **IDE:** Visual Studio
